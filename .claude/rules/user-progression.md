# User Progression Rules

## Experience Level Classification
| Level | Definition |
|-------|-----------|
| Novice | < 6 months consistent training |
| Intermediate | 6 months – 2 years, stalled on linear progression |
| Advanced | 2+ years, requires periodized programming |

## Progression Models
- **Novice**: Linear progression — add weight every session
- **Intermediate**: Weekly progression — add weight every week, use 3-day splits
- **Advanced**: Block periodization — accumulation → intensification → realization cycles

## Plateau Detection
- No strength increase in 3+ consecutive sessions on the same exercise = plateau
- Trigger: offer deload, technique review, or exercise variation
- Never silently ignore stagnation — surface it to the user

## Volume Landmarks (per muscle group per week)
| | Minimum Effective | Maximum Adaptive | Maximum Recoverable |
|---|---|---|---|
| Large (legs, back, chest) | 10 sets | 15–20 sets | 25 sets |
| Small (arms, delts, calves) | 6 sets | 10–15 sets | 20 sets |

- Warn if a generated program exceeds Maximum Recoverable Volume
- New users start at Minimum Effective Volume

## Long-Term Milestones (male / female bodyweight multiples)
| Lift | Novice | Intermediate | Advanced |
|------|--------|-------------|---------|
| Squat | 1.0x / 0.75x | 1.5x / 1.0x | 2.0x / 1.5x |
| Deadlift | 1.25x / 1.0x | 1.75x / 1.25x | 2.5x / 1.75x |
| Bench | 0.75x / 0.5x | 1.25x / 0.75x | 1.75x / 1.25x |

Use these as reference targets only — never as pass/fail gates.
